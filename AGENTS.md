## Ограничение лишних субагентов

- Не запускай general-субагента для финальной проверки, если typecheck, tests, lint и build уже успешно прошли.
- Для одной задачи используй не более одного explore-субагента.
- Не запускай повторный полный аудит diff после успешных автоматических проверок.
- После успешных проверок сразу заверши задачу и дай краткий итог.
